# Behavior Catalog

Status: Complete

The Behavior Catalog is the reference CRUD implementation for Dashboard V2.

Future admin modules should reuse its patterns where appropriate rather than recreating them.

## Desktop Behavior Display

Desktop does not use a standalone behavior Show page for normal catalog interaction.

Selecting View opens the existing right-hand detail card.

Global Search follows the same pattern:

Global Search
→ Behavior Catalog
→ matching behavior automatically selected
→ detail card displayed

Do not introduce a separate desktop Show page unless the product requirements change.

## Mobile Behavior Display

Mobile uses a dedicated Show page.

This is intentional because the desktop detail-card pattern does not translate well to the mobile layout.

## Video Behavior

Video URLs automatically detect:

- YouTube
- TikTok
- Instagram
- Facebook
- Unknown

Duplicate URLs are checked before saving.

Only one video may be marked Preferred.

Existing video rows retain their database ID during editing.

Removed video rows are deleted during update.

## Global Search

Behavior results are generated by:

App\Services\BackendSearchService

Desktop search results link to the Behavior Catalog with:

search=<behavior name>
behavior=<behavior id>

The catalog then automatically selects the matching behavior.

## Feedback

Create, update, and delete redirect with Laravel flash messages.

Global flash feedback is rendered from the Dashboard V2 shell.

## Delete

Delete appears in the reusable Danger Zone.

Confirmation uses the browser-native confirm dialog.

Successful deletion redirects to the Behavior Catalog.
